====================================================================
SECTION 2 — APPLY SNIPPET ON PROXMOX
====================================================================

Install snippet:

install -D -m 0644
kubernetes/platform/proxmox/snippets/300-userdata.yaml
/var/lib/vz/snippets/300-userdata.yaml

Attach to VM 300:

qm set 300 –cicustom “user=local:snippets/300-userdata.yaml”

Regenerate ISO:

qm stop 300 || true qm cloudinit update 300 qm start 300

Verify from PVE:

qm cloudinit dump 300 user | sed -n ‘1,200p’

====================================================================
SECTION 3 — STATIC NETWORK CONFIGURATION (RHEL)
====================================================================

Identify connection:

nmcli connection show nmcli -f NAME,DEVICE connection show

Set static IP:

nmcli connection modify “cloud-init eth0”
ipv4.method manual
ipv4.addresses 192.168.2.230/24
ipv4.gateway 192.168.2.1
ipv4.dns 192.168.2.250
ipv4.dns-search “brownrook.net,brownrook.com”
ipv6.method ignore

Apply:

nmcli connection down “cloud-init eth0” nmcli connection up “cloud-init
eth0”

Disable cloud-init network rewrites:

echo “network: {config: disabled}” | sudo tee
/etc/cloud/cloud.cfg.d/99-disable-network-config.cfg sudo cloud-init
clean sudo reboot

====================================================================
SECTION 4 — VALIDATION
====================================================================

Check cloud-init:

sudo cloud-init status –long

Check SSH:

sudo sshd -T | egrep ‘passwordauthentication|permitrootlogin’

Test login:

ssh paul@k3s1.brownrook.net

Root login must fail:

ssh root@k3s1.brownrook.net

====================================================================
NOTES
====================================================================

Cloud-init applies once per instance unless cleaned:

sudo cloud-init clean sudo reboot

Proxmox regenerates the cloud-init ISO only when:

qm cloudinit update
